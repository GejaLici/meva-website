# **App Name**: NovaSculpt Clinic

## Core Features:

- Homepage: Homepage with introductory content and services overview.
- Service Pages: Separate page for each service: FYTYRA (Face), GJOKSI (Breasts – Femra), TRUPI (Body).
- Detailed Service Pages: Dedicated page for each specific service listed in the prompt.
- Contact Form: Contact page with a form to send messages and the clinic's contact information.

## Style Guidelines:

- Base: Dark blue (#1A2E44) for a professional and trustworthy feel.
- Primary Accent: Deep blue (#2C5F9D) to highlight key elements and sections.
- Secondary Accent: Cool silver (#BCCCDC) for subtle details and borders.
- Highlight: Mint green (#7FC7B9) to draw attention to important information and CTAs.
- Background: Light grey (#F0F2F5) for a clean and modern backdrop.
- Headline font: 'Poppins' (sans-serif) for a precise, contemporary, fashionable look.
- Body font: 'Inter' (sans-serif) for a modern, neutral, objective feel. The amount of content on some pages indicates the use of a clear body font.
- Use modern and geometric icons in cool silver to complement the logo and color scheme.
- Clean and minimalist layout with ample white space to focus on content and services.
- Subtle animations on page transitions and interactive elements to add a modern touch.
